Lighting

115 LEDs, 20 expansion board(s), one USB lead.

As designed, the spaces behind the glass are closed in, so there is nowhere to run the wiring. Lighting has to be planned into a model from the start — ask for it when you ask for a price.

A light kit is bought separately and never appears in the parts list. Press Lights on to see the model after dark.
